# Cloud playground reference

Third-party reference code for the volumetric cloud technique (Babylon.js
playground `#MAONNT#13` and its volumetric-clouds plugin). The game's cloud pass in
`tech-demo/src/world/cloudVolume.ts` began as a port of this code.

It isn't compiled or shipped. It's kept only to compare against. The shader
reads its weather map and 3D noise from `tech-demo/public/textures/clouds/`
(see the CREDITS there).
